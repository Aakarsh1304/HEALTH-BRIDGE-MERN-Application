🏥 HEALTH-BRIDGE – MERN Healthcare Management System

HEALTH-BRIDGE is a full-stack healthcare management platform built using the MERN stack. It provides a centralized platform for managing patient medical records, prescriptions, medical reports, appointments, and communication between patients and doctors.

🚀 Features
👤 Patient Portal
Secure registration and login
Patient profile management
Medical history management
Upload and manage medical reports
View digital prescriptions
Book and manage appointments
Receive notifications
Review and approve or reject doctor access requests
🩺 Doctor Portal
Secure doctor login
Doctor profile management
View and manage appointments
Request access to patient medical records
View authorized patient medical history
Create and view prescriptions
Receive notifications
🔐 Security
JWT-based authentication
Password hashing
Role-based access control
Protected routes for patients and doctors
Patient-controlled access to medical records
